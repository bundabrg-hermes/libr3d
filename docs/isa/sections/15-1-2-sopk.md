# 15.1.2. SOPK

_(pages 154-155)_

### Description

This is a scalar instruction with one 16-bit signed immediate (SIMM16) input and a single destination. Instructions that take 2 inputs use the destination as the first input and the SIMM16 as the second input. E.g. "S_CMPK_GT_I32 S0, 1" means "SCC = (s0 > 1)" Table 67. SOPK Fields Table 68.
