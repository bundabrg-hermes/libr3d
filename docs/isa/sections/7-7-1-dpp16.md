# 7.7.1. DPP16

_(pages 79-81)_

DPP16 allows selection of data within groups of 16 lanes with a fixed set of possible swizzle patterns. Both VOP3/VOP3P and DPP16 have ABS and NEG fields: • VOP3’s ABS & NEG fields are used, and DPP16’s are ignored • VOP3P’s NEG/NEG_HI fields are used and DPP16’s ABS & NEG are ignored.
