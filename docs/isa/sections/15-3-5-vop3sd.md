# 15.3.5. VOP3SD

_(pages 174-175)_

### Description

Vector ALU format with three operands and a scalar result. This encoding is used only for a few opcodes. Can be followed by a 32-bit literal constant or DPP instruction DWORD when the instruction allows it.
