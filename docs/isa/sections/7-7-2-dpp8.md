# 7.7.2. DPP8

_(pages 81-81)_

DPP8 allows arbitrary cross-lane swizzling within groups of 8 lanes. There are two forms of DPP8: normal, which reads zero from lanes whose EXEC mask bit is zero, and DPP8FI, which fetches data from inactive lanes instead of using the value zero. DPP8 follows DPP16’s "BC = 1" behavior and assumes all source lanes are in-range.
