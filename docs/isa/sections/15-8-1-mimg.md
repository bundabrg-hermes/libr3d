# 15.8.1. MIMG

_(pages 189-190)_

### Description

Memory Image Instructions Memory Image instructions (MIMG format) can be between 2 and 3 DWORDs. There are two variations of the instruction: • Normal, where the address VGPRs are specified in the "ADDR" field, and are a contiguous set of VGPRs. This is a 2-DWORD instruction. • Non-Sequential-Address (NSA), where each address VGPR is specified individually and the address VGPRs can be scattered.
