# S_CMP_EQ_I32 (opcode 0)

Set SCC to 1 iff the first scalar input is equal to the second scalar input.

### Notes

Note that S_CMP_EQ_I32 and S_CMP_EQ_U32 are identical opcodes, but both are provided for symmetry.
